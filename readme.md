# Telegram-бот для генерации контента НКО

Интеллектуальный помощник для некоммерческих организаций, который помогает создавать качественный контент для социальных сетей с использованием GigaChat API.

Ссылка на бота: https://t.me/NKOASSIST1BOT

## 📋 Возможности бота

### Для сотрудников НКО:

1. **📝 Генерация текста** - создание постов для соцсетей в трёх режимах:
   - **Свободный текст** - преобразование идеи в готовый пост
   - **Структурированная форма** - пошаговое заполнение данных о событии
   - **На основе примеров** - генерация в стиле ваших готовых постов

2. **🎨 Генерация картинки** - создание детальных промптов для генерации изображений

3. **✏️ Редактор текста** - проверка и улучшение текстов:
   - Исправление орфографических и грамматических ошибок
   - Улучшение логики и структуры
   - Советы по повышению качества

4. **📅 Контент-план** - автоматическое создание плана публикаций:
   - На неделю или месяц
   - С настраиваемой частотой
   - Разнообразные типы контента

5. **ℹ️ Информация о НКО** - сбор и хранение данных об организации для персонализации контента

## 🚀 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd nko_tg_bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Установка корневого сертификата НУЦ Минцифры

Для работы с GigaChat API необходимо установить корневой сертификат:

```bash
curl -k "https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer" -w "\n" >> $(python -m certifi)
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта и заполните следующие параметры:

```env
# Telegram Bot Token (получите у @BotFather)
TOKEN=your_telegram_bot_token_here

# Database URL (PostgreSQL)
DATABASE_URL=postgresql://user:password@localhost:5432/nko_bot_db

# GigaChat API credentials
GIGACHAT_CREDENTIALS=your_gigachat_authorization_key_here
GIGACHAT_VERIFY_SSL_CERTS=False
GIGACHAT_SCOPE=GIGACHAT_API_PERS
```

### 5. Получение ключа GigaChat API

1. Перейдите в личный кабинет [GigaChat Studio](https://developers.sber.ru/studio)
2. Создайте новый проект GigaChat API
3. В разделе "Настройки API" нажмите "Получить ключ"
4. Скопируйте Authorization Key и вставьте в `.env` файл

### 6. Настройка базы данных PostgreSQL

Создайте базу данных PostgreSQL:

```bash
createdb nko_bot_db
```

Или используйте существующую, указав правильный `DATABASE_URL` в `.env`

### 7. Запуск бота

```bash
python main.py
```

2. Выберите роль "Я сотрудник НКО"
3. Заполните информацию об организации (необязательно, но рекомендуется)

- **📝 Генерация текста** - создание постов

## ⚙️ Настройка GigaChat

### Параметры в .env:

- `GIGACHAT_CREDENTIALS` - Authorization Key из личного кабинета
- `GIGACHAT_VERIFY_SSL_CERTS` - проверка SSL-сертификатов (False для отключения)
- `GIGACHAT_SCOPE` - версия API:
  - `GIGACHAT_API_PERS` - для физических лиц (по умолчанию)
  - `GIGACHAT_API_B2B` - для ИП и юрлиц (предоплата)
  - `GIGACHAT_API_CORP` - для ИП и юрлиц (постоплата)

## 🐛 Решение проблем

### Ошибка подключения к GigaChat API

Убедитесь, что:
- Установлен корневой сертификат НУЦ Минцифры
- Правильно указан `GIGACHAT_CREDENTIALS` в `.env`
- Используется правильный `GIGACHAT_SCOPE`

### Ошибка подключения к базе данных

Проверьте:
- Запущен ли PostgreSQL
- Правильно ли указан `DATABASE_URL` в `.env`
- Существует ли указанная база данных

### Бот не отвечает

Проверьте:
- Правильность `TOKEN` в `.env`
- Запущен ли скрипт `main.py`
- Нет ли ошибок в консоли
